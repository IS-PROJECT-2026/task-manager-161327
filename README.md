# 📋 Task Manager

A modern and responsive task management web application built using **HTML**, **CSS**, and **JavaScript**. The application enables users to efficiently organize their daily activities by creating, editing, deleting, searching, filtering, and completing tasks. All tasks are automatically persisted using the browser's **Local Storage**, ensuring data remains available across browser sessions.

## ✨ Features

* ➕ Create new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 💾 Persist tasks using Local Storage
* 🔍 Search tasks by title, description, or tag
* 🏷️ Filter tasks by category
* 📱 Fully responsive user interface
